# Roslavychi Home — демонстраційний прототип

Клікабельний UX-прототип кабінету мешканця котеджного містечка: заявки, пропуски,
платежі, лічильники, бронювання, голосування — з ролями мешканця, охорони КПП,
менеджера і техніка.

**Демо:** https://igorshara.github.io/roslavychi-home-demo/

Прототип для показу. Не бойова система: без backend, без реальних даних.
